## Behavior and limits

`/pig-litter` lists retained direct children. Enter opens identity and status. `v` opens the latest report. `m` drafts a message, `p` pauses the selected subtree, and `r` drafts an explicit resume with the same UUID. Escape returns or cancels. Brackets page through reports because released PiG consumes PageUp and PageDown before a custom component.

Passive opening, navigation, inspection and closure preserve root/child pause, native history and completion receipts. Explicit resume authorizes the selected direct child. Its paused descendants and siblings stay paused. A now-active worker can then explicitly resume its own child through its existing tools.

Terminal root notices use the public nextTurn delivery mode and wait for an explicit new root turn after current work settles. A full host restart can require one additional explicit prompt to recover a lost queued notice. Input steered into the current turn does not promote this queue. Inspect and wait remain immediate. RPC roots and child parents retain native completion behavior. No host patch, private queue operation or synthetic history is used.

Human rendering strips terminal sequences and unsafe controls, preserves valid text and bounds display width. Machine JSON remains raw. Elapsed time and native tool counts cover the current execution; restored timing is unknown. Reports use an explicit display-row bound.
